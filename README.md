# 阪木老大實驗室 v1.1

《寶可夢 心金／魂銀》瀏覽器版 EV（努力值）存檔修改器。

網站：<https://kane6353.github.io/HGSS-EV-Editor/>

## 功能

- 讀取 512 KB `.sav` / `.dsv` HGSS 存檔
- 修改隊伍與 PC 盒中寶可夢的 EV
- 合法模式：單項最高 252、總和最高 510
- 快速 EV 配置
- 重新加密 Gen IV Pokémon 資料並重算 Pokémon checksum
- 重算 HGSS general/storage 區塊 CRC16
- 匯出前再次驗證修改結果
- 存檔只在瀏覽器本機處理，不會上傳伺服器
- 支援 PWA / 離線快取
