# 阪木老大實驗室 v1.2

《寶可夢 心金／魂銀》Gen IV 存檔修改器，直接在瀏覽器本機處理 `.sav` / `.dsv`。

## v1.2
- 修改努力值 EV
- 修改個體值 IV（0–31、6V 快速設定）
- 修改個性 Nature
- 個性修改會調整 PID，保留 PID 低 8 位並盡量維持原本閃光狀態
- 支援隊伍與 18 個盒子
- 匯出前自動驗證 Pokémon checksum 與 HGSS CRC
- 首頁改為 network-first，降低 GitHub Pages 顯示舊版快取的機率

> 修改前請保留原始存檔。特殊活動／固定 PID 寶可夢修改個性後可能失去原始合法性。
